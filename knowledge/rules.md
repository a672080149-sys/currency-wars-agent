## 1. 模式总览

| 项目 | 标准博弈 | 超频博弈 |
|---|---|---|
| 定位 | 完整模式，按最高职级挑战 | 短时快速模式，可用于完成积分奖励 |
| 位面数 | 3 | 3 |
| 首领节点 | 1-9 / 2-7 / 3-7 | 1-6 / 2-5 / 3-5 |
| 位面节点数 | 第一位面 9、第二位面 7、第三位面 7 | 第一位面 6、第二位面 5、第三位面 5 |
| 难度选择 | 由当前最高职级决定，可手动降级（不消耗资源） | 依据标准博弈达到的最高职级 |
| 结算 | 积分 + 晋升点（18000 积分、1500 基础晋升点 + 每难度 5%/最高 80% + 额外 2700） | 积分 + 晋升点 + 等价钻钞（18000 积分、1000 基础 + 每难度 5%/最高 80% + 额外 1500） |
| 失败惩罚 | 不降低当前职级 | 同左 |

- 参与条件：开拓等级 ≥ 21；支持「终末视界」提前体验。
- 积分奖励：每双周周一 04:00（服务器时间）重置；阈值 1800/3600/…/18000，总计 星琼 225、星轨通票 1、黑塔债券 1、命运的足迹 1、深度沉浸器 4、助燃券 50、遗失晶块 21、信用点 300000。
- 来源：<https://wiki.biligame.com/sr/货币战争#标准博弈>、`currency_wars.py` 常量 `BOSS_STAGES`

### 位面与节点结构（要点）

- 每局 3 个位面，每个位面末尾是首领节点（「挑战成功 / 挑战失败」结算页）。
- 位面 1 的节点序列为普通战斗/遭遇/奖励/补给混合，最终 1-9 为首领；位面 2、3 各 7 个节点，首领在 2-7、3-7。
- 超频博弈节点更少（6/5/5），首领位置前移，因此经济与成型的容错更低。
- 每个节点结束后进入「备战阶段」：自动刷新 1 次商店、可购买角色/经验/装备、可调整站位。
- 「最终首领」是第三位面的首领节点；其后无更多节点。
- 未找到：每一位面内各节点类型的确切排列（wiki 未给出固定表，游戏内为随机+固定混合）。

## 2. 职级体系

### 2.1 大职级（9 档）

`黑铁 → 青铜 → 翠钢 → 钴银 → 冰钛 → 紫金 → 投资大师 → 资本帝王 → 财富造物主`

来源：`currency_wars_ui.py` 常量 `RANK_NAMES`（游戏内经 OCR 核对的正式服名称）。

### 2.2 小职级（A1–A8）

- 每个大职级下还有 A1–A8 的小档（界面左上角显示如 `A3`），代码 `rank_tier` 按 `A([0-8])` 解析。
- 提升时显示「职级提升」，并展示新职级名。

### 2.3 晋升规则（标准博弈）

| 通关时剩余小队生命值 | 职级提升 |
|---|---|
| ≥ 70 | +3 |
| ≥ 40 | +2 |
| < 40 | +1 |

- 晋升至对应职级时获得星琼与晋升点；失败不降级。
- 「晋升赛」：界面提示「通关晋升赛后可晋升至下一职级」「晋升赛难度将大幅提升」。
- 晋升点：标准博弈 18000 积分档位下 1500 基础 + 按难度 5%/最高 80% + 额外 2700；超频博弈 1000 基础 + 额外 1500。

### 2.4 敌人难度

- 职级页显示一个「敌人难度」数值（1 起，可手动降级到 1），难度越高敌人越强并附带更多词缀（界面显示「词缀数量」）。
- 高难度下敌人获得词缀（见第 7 节）。
- 来源：`currency_wars.py` `_select_rank`/`_select_lowest_rank`、`currency_wars_ui.py` `rank_affixes`

## 3. 经济：金币、等级、人口

### 3.1 金币来源

1. 战斗结束的基础金币奖励。
2. **利息**：按当前持有金币结算（界面在每场战斗结算时给出）。
3. **连胜奖励**：连续获胜获得额外金币（连胜数界面可见；投资策略「胜利，还是胜利」可直接把连胜数设为 4，「嘴硬」可保住连胜）。
4. 各类投资环境/策略与羁绊（如「公司」羁绊普通战斗与遭遇节点开始 +1/+3 金币）。

- 利息上限：**推断为 5 金币**。依据：「开源节流」使「利息上限提升至 9」、「利息上调」使「最大利息提升至 10」、「买断制」描述「你不再获得利息」。
- 未找到：利息的每档金币数与连胜奖励的确切数值表。

### 3.2 等级（商店等级 / 团队规模）

- 等级 1–10（超频/特殊策略可到 11：「幻月游戏·经验」的 10 级效果可使商店升至 11 级；「控制规模」会锁定最大等级为 7）。
- 购买经验：**4 金币 / 次，每次 +4 经验**（代码 `experience_purchases` 以 4 点为一档计算所需次数；`_can_expand` 判定经验价格为 4）。
- 等级决定**可上阵人口**（界面显示 `已用/上限`，上限范围 3–14）；「财富宝钻」额外 +1 团队规模上限。
- 未找到：等级 → 人口的确切对应表（代码只按读取到的 `used/capacity` 运作，未写死映射）。

### 3.3 商店刷新概率（官方表）

| 等级 | 1费 | 2费 | 3费 | 4费 | 5费 |
|---|---|---|---|---|---|
| Lv.1 | 100% | - | - | - | - |
| Lv.2 | 100% | - | - | - | - |
| Lv.3 | 100% | - | - | - | - |
| Lv.4 | 65% | 25% | 10% | - | - |
| Lv.5 | 45% | 33% | 20% | 2% | - |
| Lv.6 | 30% | 40% | 25% | 5% | - |
| Lv.7 | 19% | 30% | 40% | 10% | 1% |
| Lv.8 | 18% | 25% | 32% | 22% | 3% |
| Lv.9 | 15% | 20% | 25% | 30% | 10% |
| Lv.10 | 5% | 10% | 20% | 40% | 25% |

- 商店 5 个栏位；每节点自动刷新 1 次；手动刷新基础 **2 金币**（「融资危机」词缀会临时改为 3 金币）。
- 可锁定商店，锁定后不自动刷新。
- 来源：<https://wiki.biligame.com/sr/货币战争#刷新概率>

### 3.4 角色星级与合成

- 角色初始 1 星；**招募 3 个相同星级的同名角色自动升星**（1→2→3），3 星通常为最强形态（官方旁注：「4 星其实更强，但是极其苛刻」，指部分机制可临时升到 4 星，如「超光速提拔」「星变」「战场进化手册」）。
- 2 星卡的商店售价 = 3 倍基础费用（代码 `expected = base_cost * 3`）。
- 出售价格：按投入折算（界面显示 `+N`）；「大裁员 / 降本增效」可按双倍价格出售全部角色。

## 4. 血量与伤害

- 小队生命值：初始为一固定值（界面读取上限按 150 处理；多处数值提示以 100 为满值，**未找到官方初始值文本**）。
- 战斗失败/未在倒计时内清场 → 扣除一定小队生命值；生命值归 0 结束对局（「挑战失败」）。
- 职业化阈值（社区与本地代码常用）：≤65 视为需要保命、≤55 视为紧急、≤48 需要保留后台生存位、≤45 停止升级存钱、≤35 停止利息运营、≤40 影响晋升档位。
- 倒计时（行动值）：进入战斗后开始计时，倒计时归零即失败。
- 未找到：单次失败扣血公式、不同节点（普通/精英/首领）的扣血差异。

## 5. 装备系统

- 分「简易装备」「进阶装备」「特权装备」；**2 件简易装备合成 1 件进阶装备**（继承两件材料的全部数值 + 唯一战斗效果）。
- 进阶装备可再升级为「特权装备」（特权赋予卡、融合召唤等）。
- 每个角色 3 个装备栏；「随便骰子」需要空栏位才能装备。
- 拆装：拆装扳手 / 精密拆装扳手（精密拆装不损失材料，「精密拆装•银/金/彩」策略会发放）。
- 装备来源：奖励节点、补给节点、武装箱、开拓商店、黑市、晶矿、投资策略。
- 详见 `equipment.json`。
