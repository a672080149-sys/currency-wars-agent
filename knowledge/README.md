## 三、已知的命名冲突（重要）

S2 正式服改过部分名称，而 wiki 尚未同步，**同一件东西在资料里可能出现两个名字**：

| wiki 名（合成表） | 本地代码（S2 正式服 OCR） | 说明 |
|---|---|---|
| 电光履（光能电池 + 轮滑鞋） | **星航履** | 配方一致，wiki 页面「星航履」不存在 |
| 步步生花（生命之花 + 轮滑鞋） | **反螺旋舞步** | 配方一致，wiki 页面「反螺旋舞步」不存在 |
| 珍珠 | **真珠** | 同一角色（幻月游戏/千星商会/守护，1 费后台治疗），wiki 存在两个标题的重复页 |

处理方式：`equipment.json` 以 wiki 名为主，`note` 字段标注本地名；`characters.json` 统一用「真珠」。

- **`traits.json` 的赛季归属**：部分词条（护盾、战技点、燃血、量子同频、仙舟、列车同行、贝洛伯格、云上五骁、盛会之星、银河学者、夜之半神、昼之半神、狼狩、命运卜者、救世主、挚爱之人、大魔术师、领航员、大守护者、命运圣杯、头号玩家）的 wiki 源码未写 `赛季=` 参数，只能按「实装版本 + 是否出现在 S2 角色羁绊列表」判断；已在 `season` 字段标注「未标注」或「零和博弈」。
- **击破 / 星核猎手 / 欢愉 / 持续伤害 / 群攻 / 治疗 / 能量 / 星间旅人 / 巡海游侠 / 幻月游戏** 等词条的资料同时存在两个赛季版本，`traits.json` 一律取 **入画奇航** 版本。
- **`investments.json` 的位面字段**：来自 wiki 原表「出现位面」，同一策略在不同位面可能数值不同（如 特战资金 / 特战资金+），属正常。
- **装备特效**：36 件进阶装备的效果已逐条从 wiki 条目页取得；8 件简易装备通常只有基础属性、无描述（表内 `effect` 为空即为原文如此）。

## 五、给使用者的建议（如何查询）

1. 查某角色：「费用 / 站位 / 羁绊」→ `characters.json`；「这个羁绊几级有什么效果」→ `traits.json` 的 `tiers`。
2. 查某装备怎么合 → `equipment.json` 的 `recipe` 数组（两件材料）；反向查「这件材料能合什么」可遍历 `advanced[].recipe`。
3. 查某投资策略在不在这局能刷到 → `investments.json` 的 `planes`（1/2/3 位面）。
4. 查首领是谁、带什么小怪 → `nodes_events.json` 的 `competitors`；查词缀 → `rules.md` 第 7 节。
5. 想打高难 → 先读 `firefly_guide.md`，再回 `traits.json` 核对击破/星核猎手/连击档位。
